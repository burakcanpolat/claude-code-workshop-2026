ModelAnthropic's positioningDefault on

BLOCK 22.4 MODELS AND EFFORT51

LevelAnthropic's own description
lowMost efficient. Significant token savings with some capability reduction
mediumBalanced approach with moderate token savings
highEquivalent to not setting the parameter. This is the default
